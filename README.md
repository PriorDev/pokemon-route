# PokeRouteJC

This is an open source project developed to learn and experiment with modern Android development technologies and best practices. It serves as a playground for implementing new features and exploring the Android ecosystem.

## Overview

PokeRouteJC is a Pokedex application built using Jetpack Compose and Clean Architecture. It demonstrates how to build a scalable and maintainable Android application using modern libraries and tools.

## Features

- **Pokedex**: Browse a list of Pokemon.
- **Pokemon Details**: View detailed information about specific Pokemon, including stats, types, and evolution chains.
- **Search**: Search for Pokemon by name.
- **Type Information**: Explore Pokemon types and their relationships.
- **GraphQL Integration**: Fetches data efficiently using GraphQL.

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose (Material 3)
- **Architecture**: Clean Architecture (Presentation, Domain, Data), MVVM
- **Dependency Injection**: Koin
- **Networking**: Apollo GraphQL, Ktor
- **Local Storage**: Room, DataStore
- **Asynchronous Programming**: Coroutines, Flow
- **Image Loading**: Coil
- **Navigation**: Navigation Compose
- **Code Quality**: Detekt
- **Testing**: JUnit 5, Mockk, Turbine, AssertK

## Note

This project is primarily for learning and educational purposes.
